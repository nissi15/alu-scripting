# Regular Expressions

This project focuses on understanding and practicing regular expressions using Ruby and the Oniguruma library.

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* All files will be interpreted on Ubuntu 20.04 LTS
* All files end with a new line
* A `README.md` file at the root of the folder of the project is mandatory
* All Bash script files must be executable
* The first line of all Bash scripts should be exactly `#!/usr/bin/env ruby`
* All regex must be built for the Oniguruma library

## Tasks

| File | Description |
| --- | --- |
| `0-simply_match_school.rb` | Matches `School` |
| `1-repetition_token_0.rb` | Matches repetition cases for token #0 (`hbt{2,5}n`) |
| `2-repetition_token_1.rb` | Matches repetition cases for token #1 (`hb?tn`) |
| `3-repetition_token_2.rb` | Matches repetition cases for token #2 (`hbt+n`) |
| `4-repetition_token_3.rb` | Matches repetition cases for token #3 (`hbt*n`) without square brackets |
| `5-beginning_and_end.rb` | Matches a string that starts with `h`, ends with `n`, and has any single character in between |
| `6-phone_number.rb` | Matches a 10-digit phone number |
| `7-OMG_WHY_ARE_YOU_SHOUTING.rb` | Matches only capital letters |
| `8-textme.rb` | Parses SMS log transactions and outputs `[SENDER],[RECEIVER],[FLAGS]` |
| `9-passed_linkedin_regex_challenge.jpg` | Screenshot of the LinkedIn regex challenge completion |
